# Self-Consistency Checking for Indirect Prompt Injection Defense in Email Agents

Ryan Merritt

Kansas State University

Master of Science in Integrated Systems Design and Dynamics

This repository contains the experimental harness, analysis code, and results files for a study of self-consistency checking (SCC) as a mitigation for indirect prompt injection (IPI) in LLM-based email agents. Methods, results, and discussion are in the thesis.
